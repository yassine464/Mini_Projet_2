# accessoires-app

Projet Angular 19 : gestion des Accessoires et des Marques.

## Lancer
```
npm install
ng serve
```
Puis http://localhost:4200

## Comptes de test
- admin / 123  (rôle ADMIN : ajout, modification, suppression, gestion des marques)
- yassine / 123  (rôle USER : consultation et recherche seulement)

## Contenu
- Ateliers 1, 2, 3 : liste, ajout, modification, suppression des accessoires
- Association Accessoire / Marque
- Recherche : par marque, par nom (keyup), par nom (pipe)
- Mini projet sprint 01 : authentification, droits d'accès, guards, LocalStorage
- Mini projet sprint 02 : @Input / @Output, gestion des marques (liste-marques, update-marque)
